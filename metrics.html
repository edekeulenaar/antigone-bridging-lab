3 · Define your bridging metrics

A bridging metric is a property of a comment that, if comments with it came first, would help the two sides understand each other. Define three. Each needs a coding rule precise enough that two people — or a person and a chatbot — reading the same comment would both say yes or both say no.

Base them on your close reading. If the sides talk past each other because one argues facts and the other values, a metric could pick out comments that address both. If a minority position receives little attention, a metric could move it up. Start from a template below if you like, but rewrite it for your thread: say which statements, how many, which side.
