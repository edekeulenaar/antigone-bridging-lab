3

Run it

  1. Open a chatbot (ChatGPT, Claude, Gemini, Mistral, DeepSeek…), attach your CSV and paste the prompt. It adds three columns, metric_A, metric_B and metric_C, with yes or no for every comment.
  2. Download the CSV it returns and check that every row came back. If the chatbot stops part-way, split the thread into parts on the same page (below) and send each part with the same prompt.

If the chatbot prints the CSV as text instead of a file, copy all of it into a plain-text editor and save it as .csv. Use the same chatbot for every part, and note its name and the date.

Check the chatbot's coding

Add the columns mine_A, mine_B and mine_C to the returned file and code 20 comments yourself, without looking at the chatbot's answers. The next page shows how often you agree. If you agree on fewer than about 8 in 10 (a rule of thumb for this assignment, not an established threshold), make the rules more precise and run the prompt again.
