Code a sample with an LLM

You have no API, so the model is a chat window: this page turns your codebook and your sample into prompts you paste into a chat model, a batch at a time, and reads its answers back into your sample. Then it checks the model's coding against items you coded by hand, because a coding you have not validated is not a finding.

Any chat model available to you will do (ChatGPT, Claude, Gemini, Mistral, DeepSeek…). Free versions take shorter prompts and may stop part-way: keep batches small, start a new chat for each batch, and check that every ID came back. Use the same model for every batch, and note which one you used.
